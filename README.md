# FarEastCTF 2026 — пакет для вёрстки лендинга

Макеты из pen.dev, подготовленные для Codex: desktop 1440 (`pqxdh`) и mobile 390 (`TOoAz`), плюс открытое мобильное меню и состояния формы.

## Как запустить

Откройте эту папку в Codex (приложение или `cd ~/FarEastCTF-2026-landing && codex`) и напишите:

> Сверстай лендинг по AGENTS.md

Codex сам прочитает `AGENTS.md`, а сайт соберёт в папке `site/`.

## Что внутри

| Путь | Что это |
|---|---|
| `AGENTS.md` | задание и правила для Codex |
| `docs/SPEC.md` | спецификация по секциям: сетка, размеры, компоненты, адаптив, форма |
| `docs/CONTENT.md` | все тексты, ссылки и список незаполненных `[плейсхолдеров]` |
| `tokens/` | цвета, шрифты, типографика (CSS-переменные + JSON) |
| `assets/` | готовые картинки, «глаз» с полутоном, иконки, штриховка |
| `design/screens/` | эталонные скриншоты: целиком и по секциям (@2x) |
| `design/spec/` | точные данные макетов в JSON |
| `design/*.html` | HTML-экспорт pen.dev для сравнения в браузере |

## Когда придут данные от организаторов

Все незаполненные значения (адреса, время, дедлайн, размер команды, условия, ссылки на документы, логотипы, адрес отправки формы) перечислены в конце `docs/CONTENT.md`. После вёрстки они будут собраны в одном файле контента в `site/` — заменить их можно там.
