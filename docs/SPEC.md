# Спецификация вёрстки — лендинг FarEastCTF 2026

Макеты: **desktop 1440 px** (pen.dev `pqxdh`) и **mobile 390 px** (pen.dev `TOoAz`).
Дополнительно: открытое мобильное меню (`BdUfb`) и состояния формы (`i62t5`).
Все размеры — в CSS-пикселях макета. Цвета и шрифты — токены из `tokens/tokens.css` (`--line`, `--accent` и т.д.).

Где смотреть точные значения:
- картинка секции — `design/screens/{desktop|mobile}/NN-*.png` (2x), длинные секции порезаны в `parts/`;
- дерево узлов с отступами, размерами и стилями — `design/spec/{desktop|mobile}.json` (имена узлов совпадают с названиями ниже: «Hero / Column», «Format Heads», «Spec Label»…);
- готовый рендер для сравнения в браузере — `design/desktop.html`, `design/mobile.html` (это экспорт pen.dev с абсолютными px, **не** код для продакшена).

## 1. Глобальная система

### 1.1 Брейкпоинты

| Диапазон | Макет | Поля страницы (`--gutter`) | Колонна |
|---|---|---|---|
| < 1024 px | mobile (390) | 16 px | 100% − 2×16 |
| 1024–1439 px | desktop (1440) | 32 px (рекомендация) | 100% − 2×32 |
| ≥ 1440 px | desktop (1440) | 80 px и больше | max 1280, по центру |

- Mobile-макет тянется от 320 до 1023 px: одна колонна, всё по ширине.
- Desktop-макет построен на колонне 1280: Formats / Merch / Support / Apply — трети (~428 | 426 | 426); Hero Info и Footer — 4 равные колонки; Partners — 5 колонок; «Стать партнёром» — 768 | 512 (60 / 40). Делайте сетки в `fr`/процентах, а не в px, чтобы при 1024–1439 колонна сжималась пропорционально.
- Крупная типографика между брейкпоинтами — через `clamp()`: заголовок Hero `clamp(68px, 11.67vw, 168px)`, вордмарк футера `clamp(58px, 14.6vw, 210px)`, h2 секций 34 → 56 (например, `clamp(34px, 3.9vw, 56px)` на desktop).
- На ≥ 1440 горизонтальные линии секций идут на всю ширину окна, вертикальные — только по краям колонны 1280.

### 1.2 Каркас «чертёжной» сетки — главный визуальный приём

Каждая секция устроена одинаково:

```
<section> — во всю ширину окна, фон --bg, border-bottom 1px --line, padding-inline: --gutter
  └─ .column — max-width 1280, margin auto, border-left + border-right 1px --line
       └─ содержимое: ячейки, разделённые линиями 1px --line
```

- Все линии — 1px `--line` (#232323). Рамки элементов управления (кнопка secondary, теги, поля, иконки-боксы) — 1px `--line-strong` (#363636).
- **Линии не удваиваются.** В pen.dev обводки внутренние и накладываются друг на друга; в CSS на стыке ячейки и рамки колонны должна остаться одна линия 1px (у крайних ячеек убрать свою границу, либо рисовать разделители только между ячейками: `border-left` у всех, кроме первой).
- **Метки «+» (Grid Mark)** — на каждой границе между секциями, там где горизонтальная линия пересекает рамку колонны: иконка `plus` 13×13, цвет `--text-tertiary`, центр — точно на пересечении (в макете: `x = край колонны − 6`, `y = −7` относительно верха секции). На desktop — 2 метки на секцию (левый и правый край колонны), на mobile тоже 2 (x = 10 и 368 при ширине 390). Нет у навигации. Делайте псевдоэлементами `::before/::after` у секции, `pointer-events: none`, `aria-hidden`.
- **Акцентная метка** красная (`--accent`) — одна, в блоке «Стать партнёром» (см. Partners).
- **Штриховка (Hatch)** — диагональные линии «/» 1px `--line` с шагом 10 px по горизонтали. Готовый тайл: `assets/svg/hatch.svg` (`background: url(hatch.svg) repeat`). Где: пустая угловая ячейка таблицы форматов (desktop), заполнитель под боковой колонкой заявки (desktop), полосы высотой 28 px (mobile, Formats и Apply), заполнитель в мобильном меню.

### 1.4 Повторяющиеся элементы

**Кнопка primary** (`Button / Primary`): фон `--accent`, текст и иконка `--accent-ink` (#fff); padding 15×20; gap 14; Geist Mono 500 13, ls 0.6, UPPERCASE; иконка 16 (по умолчанию `arrow-right`); углы 0. Варианты: в навигации desktop padding 11×16; в mobile-навигации `ЗАЯВКА` — padding 10×14, текст 12, без иконки; на mobile в Hero/Partners/Apply кнопки во всю ширину, `justify-content: space-between` (текст слева, иконка справа).

**Кнопка secondary** (`Button / Secondary`): прозрачная, border 1px `--line-strong`, текст `--text-primary`, иконка `arrow-down`; размеры как у primary.

**Текстовая ссылка-CTA**: `ПОДАТЬ ЗАЯВКУ →` (Geist Mono 500 13, ls 0.6, `--accent`, иконка 16 `--accent`, gap 8) и `ПРАВИЛА ФОРМАТА ↗` (то же, цвет `--text-primary`, иконка `arrow-up-right`).

**Тег**: border 1px `--line-strong`, padding 5×8, Geist Mono 12, ls 0.6, `--text-primary`, UPPERCASE; теги в ряд с gap 6 и переносом (`flex-wrap`).

**Плейсхолдер `[значение]`** (`Placeholder`): фон `--placeholder-bg`, border 1px `--placeholder-border`, радиус 3, padding 3×8, Geist Mono 13, `--placeholder-text`. Это пометка «данных пока нет» — на сайте выглядит именно так, пока организаторы не пришлют значения. Где в макете плашка растянута на ширину ячейки — текст в ней переносится.

**Тег на фото** (`Image Tag`): фон `--bg`, border 1px `--line-strong`, padding 5×8, Geist Mono 12, ls 0.6, `--text-secondary`; позиция top/left 20 (mobile 16).

**Иконка в рамке** (`Icon Box`): 48×48 (mobile 44×44), border 1px `--line-strong`, иконка 20 по центру, `--text-primary`.

**Строка характеристик** (Spec row): border-top 1px `--line`, padding 12 0, gap 16 (mobile 12); подпись — Geist Mono 11/1.45, ls 0.6, `--text-tertiary`, фикс. ширина 128 (mobile 104), переносится; значение — Geist 15/1.4 `--text-primary` или плейсхолдер на всю оставшуюся ширину. На mobile `align-items: center`, на desktop — `start`.

**Telegram-ссылка**: иконка `send` 15–16 `--accent` + текст Geist Mono 14, ls 0.2, `--text-primary`, gap 8 (в футере mobile — 13, ls 0).

**Чип координат**: фон `--bg`, border 1px `--line-strong`, padding 6×10, gap 8; красная точка 6×6 (круг, `--accent`) + Geist Mono 12 (mobile 11), ls 0.6, `--text-secondary`.

### 1.5 Иконки

Все иконки — lucide, готовые SVG в `assets/icons/` (`fill="currentColor"`, контур уже залит — `stroke` не нужен): `arrow-right`, `arrow-down`, `arrow-up-right`, `plus`, `menu`, `x`, `send`, `file-text`, `layout-grid`, `crown`, `chevron-down`, `check`, `loader`, `triangle-alert`. Размер задаётся CSS (13–20 px, см. секции), цвет — через `color`. Декоративные иконки — `aria-hidden="true"`.

- Обязательные — поля со `*` (см. CONTENT.md) + проверка email и телефона. Маска телефона `+7 (___) ___-__-__`.
- Участники: «Добавить» создаёт карточку с номером N+1, «Удалить» убирает карточку и перенумеровывает остальные. Начальное состояние — 2 карточки, как в макете. Ограничения min/max берутся из `[N]…[N]` (TBD) — до подтверждения держите их в конфиге с TODO.
- Ошибка состава команды (плашка) — над кнопкой отправки, если число участников вне диапазона.
- «Субъект РФ» — полный список субъектов РФ. Размеры футболок — список TBD (временный список держите в конфиге с пометкой TODO).
- При загрузке ничего не выбрано: «Зачёт» пустой, чекбоксы сняты. В макете «Вуз», Jeopardy и «Планирую участвовать…» отмечены — по ним видно, как выглядит выбранное состояние.
- Отправка: адрес обработчика TBD. Сделайте функцию отправки с конфигурируемым endpoint (JSON); пока endpoint пустой — имитируйте задержку и успешный ответ, а данные выводите в консоль. После успеха содержимое формы заменяется блоком «Успех». При ошибке сети/сервера — плашка «Не удалось отправить…» над кнопкой, введённые данные сохраняются.

## 5. Интерактив, которого нет в макете (решения по умолчанию)

- Навигация **sticky** сверху (фон `--bg`, линия снизу). Для якорей — `scroll-margin-top` = высоте шапки.
- Плавная прокрутка к якорям; при `prefers-reduced-motion: reduce` — без анимаций.
- Hover: ссылки и пункты навигации → `--text-primary`; primary-кнопка → светлее на ~8%; secondary и рамочные элементы → рамка `--text-tertiary`; ячейки партнёров и строки «При поддержке» → фон `--surface`, стрелка `--text-primary`. Переходы 150 ms.
- Фокус с клавиатуры: `outline: 2px solid var(--accent); outline-offset: 2px` у всех интерактивных элементов.
- Никаких анимаций появления, параллакса и т.п. — в макете их нет.
