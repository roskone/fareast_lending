# FarEastCTF 2026 — сайт

Адаптивная страница на HTML, CSS и JavaScript. Все ресурсы включены, внешние зависимости для запуска не нужны.

## Просмотр

Откройте `index.html` в браузере либо запустите из этой папки:

```sh
python3 -m http.server 8080
```

Затем откройте http://localhost:8080.

## Настройка

Тексты, ссылки и значения […] находятся в `content.js`.
В `CTF_CONFIG.endpoint` укажите URL обработчика POST-запросов JSON.
Пока он пустой, отправка демонстрационная: задержка, вывод данных в консоль и экран успеха. Заявки не сохраняются.
Значения `teamMin`, `teamMax`, `captainCounts` ожидают подтверждения организаторов. Сетка размеров временная.
Неизвестные ссылки оставлены `#`; исходные […] сохранены по заданию.

## Анимации (по запросу пользователя 19.10.2026)

Слой анимаций вынесен в `motion.css` и `motion.js`; чтобы отключить его, уберите эти два файла из `index.html`.
Все анимации включаются только классом `html.motion`, который ставится, если не задан `prefers-reduced-motion: reduce`. Конечные состояния совпадают с макетом.

- Hero: поочерёдное появление строк, «расшифровка» заголовка точечным шрифтом, выезд плашки координат.
- Прокрутка: появление блоков со сдвигом по времени, метки «+» доворачиваются на место, по линиям сетки пробегает световая полоса.
- Под шапкой — красная полоска прогресса прокрутки; активный пункт меню подчёркнут (работает и при reduced motion).
- Дата и номера форматов «расшифровываются» при появлении; в футере по вордмарку проходит блик.
- Hover: стрелки сдвигаются по направлению, блик на основных кнопках, подсветка под курсором в ячейках партнёров и поддержки, поворот иконок форматов, лёгкий зум фото мерча.
- «Глаз»: сканирующая линия и параллакс за курсором (только мышь).
- Пульс красных точек, мигание точки логотипа, медленный дрейф штриховки.
- Мобильное меню: пункты выезжают по очереди. Форма: появление и удаление карточек участников, встряхивание плашки ошибки, анимация галочек и экрана успеха.
